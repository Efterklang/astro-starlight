---
title: vim Operator
---

| Operator | Description                           | Example                                                |
| -------- | ------------------------------------- | ------------------------------------------------------ |
| `y`      | Yank (copy)                           | `yy` (yank line), `yw` (yank word)                     |
| `d`      | Delete                                | `dd` (delete line), `dw` (delete word)                 |
| `c`      | Change (delete and enter insert mode) | `cc` (change line), `cw` (change word)                 |
| `~`      | Swap case                             | `~` (swap case of character under cursor)              |
| `gU`     | Convert to uppercase                  | `gUw` (uppercase word)                                 |
| `gu`     | Convert to lowercase                  | `guw` (lowercase word)                                 |
| `>`      | Shift right                           | `>>` (indent line), `>ap` (indent paragraph)           |
| `<`      | Shift left                            | `<<` (outdent line), `<ap` (outdent paragraph)         |
| `=`      | Auto indent                           | `==` (auto indent line), `=ap` (auto indent paragraph) |
